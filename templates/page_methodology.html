Cómo funciona este sitio

Reunimos las alertas oficiales sobre productos retirados en España y las presentamos de forma que se puedan buscar por marca, producto, lote o código de barras.

De dónde salen los datos

  • AESAN (Agencia Española de Seguridad Alimentaria y Nutrición): alertas alimentarias publicadas en su web.
  • Próximamente: Safety Gate (sistema europeo de alerta para productos no alimentarios), la red de alerta de Consumo y la AEMPS.

Cómo se procesan

  • Cada día un proceso automático revisa la web de la fuente y descarga las alertas nuevas.
  • Los datos de producto (nombre, marca, lote, fechas, código de barras) se copian tal y como los publica la fuente. No añadimos valoraciones sobre productos ni marcas.
  • Las alertas recientes se vuelven a comprobar para recoger ampliaciones (nuevos lotes o productos). Cada página indica si ha sido actualizada.
  • La clasificación por tipo de riesgo, alérgeno, comunidad y supermercado se hace automáticamente a partir del texto oficial. Puede contener errores: la referencia es siempre la fuente enlazada en cada alerta.

Limitaciones

Que un producto no aparezca aquí no garantiza que sea seguro. Puede haber retraso entre la publicación oficial y su aparición en este sitio. En caso de duda, consulta la fuente oficial.

Uso de inteligencia artificial

El mantenimiento del sitio está automatizado y una persona supervisa los cambios de diseño, contenido editorial y método. Los datos de las alertas no se generan con IA: se extraen de las fuentes oficiales.
